# Prior Work and Novelty Tracking

Use this document to track related research before making novelty claims.

For each relevant paper or system, record:

- Citation
- Year
- Dataset(s)
- Modality/modalities
- Model/architecture
- Main contribution
- Evaluation setup
- Limitations
- Similarity to this project
- What remains distinct in our work

## Novelty Claims

No novelty or patentability claim should be treated as established until it is supported by a documented prior-work comparison.
